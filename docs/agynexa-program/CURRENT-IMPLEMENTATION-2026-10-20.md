## الحسابات وقاعدة البيانات

المشروع الصحيح `xsyxvswbiptbyxyqhdim`، اتصال Supabase باسم **agynexa**؛ لا يستخدم هذا المنتج مشروع المالك الآخر. نجح اتصال MCP ثم اتصال Vercel بالمفتاحين بعد تصحيح مسار فحص المفتاح العام. كان العيب في الفحص، وليس دليلًا على خطأ قيمة المفتاح. [إيصال الاتصال](releases/SUPABASE-CONNECTION-2026-10-20.md).

التسجيل والدخول والخروج منفذة. ينشئ الخادم حسابًا مؤكدًا تلقائيًا دون رسالة تحقق أو ترحيب، كما طلب المالك. هذا لا يثبت ملكية البريد. الجلسات HttpOnly، والعزل بهوية المستخدم والجلسة والعضوية وRLS، وليس بنطاق البريد أو user_metadata. الموجزات تحفظ وتقرأ وتحذف بملكية المستخدم مع موافقة في API وتكرار آمن؛ تنزيل TXT وmailto باقيان، وفتح مسودة بريد لا يثبت إرسالها.

المصدر التشغيلي: [مهاجرات Supabase](../../supabase/migrations)، [عقد APIs الحالي](architecture/current-api.openapi.json). طُبقت هجرتا الحسابات وثلاث مهاجرات Studio. توجد 13 table عامة محمية بـRLS بحسب إيصال Studio، وبعض جداول الخدمة بلا سياسات مستخدم عمدًا. timestamps مهاجرات Studio المستضافة تختلف عن أسماء الملفات المحلية؛ [إيصال قاعدة البيانات](agent-studio/evidence/stage-cde/database.json) يربطها ببصماتها. **لا تعِد تطبيقها آليًا اعتمادًا على اختلاف الأسماء.** حُذفت حسابات وبيانات التحقق المصطنعة وصلاحيات evaluator؛ لم تعدل حسابات المالك الحقيقية.

باقي حدود البيانات: `consent_at` الافتراضي لا يثبت مرور الإدراج المباشر بموافقة الواجهة، وحذف الموجز يحرر حصته لأن السقف يعد السجلات الباقية. تحذير تعطيل حماية كلمات المرور المسربة رُصد ولم يغير إعداد Auth. الاستعادة والاحتفاظ المؤسسي غير مكتملين.

## وظيفة الذكاء الاصطناعي والنماذج

المحرك يجيب من معرفة الوكيل المضافة، ويرفق المصادر، ويمكنه اقتراح طلب دعم داخلي يراجعه المالك قبل تنفيذه. لا ينشئ خدمات أعمال مستقلة أو يشغل أدوات خارجية تلقائيًا. الأدلة السابقة تثبت استدلالًا حقيقيًا بالمفاتيح الثلاثة؛ سياسة النماذج التالية تعكس السجل البرمجي بتاريخ التقرير، لا ضمانًا دائمًا من المزود.

| متغير الخادم | النموذج في السجل | الاستخدام الفعلي |
|---|---|---|
| `GROQ_API_KEY` | `openai/gpt-oss-120b` | إنتاج، الوضع «متقدم / Advanced» |
| `GROQ_API_KEY_2` | `openai/gpt-oss-20b` | إنتاج، الوضع «سريع / Fast» |
| `GROQ_API_KEY_3` | `qwen/qwen3.8-27b` | Preview، تقييم داخلي فقط؛ لا اختيار عام أو fallback تلقائي |

يمكن مقارنة نموذجي الإنتاج بالتزامن عند طلب المقارنة؛ لا تعمل النماذج الثلاثة في كل رسالة. تعدد المفاتيح لا يثبت حصصًا مستقلة. مفاتيح الخادم لا تظهر في المتصفح. المنتج نصي حتى لو وصف سجل المزود قدرات أخرى للنموذج. [السجل البرمجي](../../lib/studio/models.ts) و[نتائج التقييم](agent-studio/STAGES-CDE.md).

الضوابط المنفذة: مصادر معزولة قبل الاسترجاع، استجابة منظمة، حصر معرفات الاستشهاد في المقاطع المسترجعة، وإرفاق النص الأصلي من الخادم. `answerable=false` ينتج رفضًا واضحًا. صحة أصل الاستشهاد ليست ضمانًا لصحة كل استنتاج. حذف المصدر يمنع الاسترجاع اللاحق ويبطل نتيجة تشغيل متأخرة؛ إجابات السجل القديمة تبقى للمالك ولا تستخدم كمعرفة جديدة.

التشغيل محفوظ مع snapshots وتكرار آمن وحدود تزامن ووقت وإلغاء وإعادة محدودة لـ429. الاستهلاك يعرض tokens ومدة وتكلفة تقديرية، لا فوترة. لا تنفيذ كود/SQL/HTTP اعتباطي، ولا كشف reasoning داخلي. موافقة الدعم مرتبطة بمقترح محدد، صالحة 15 دقيقة، وتنَفذ مرة واحدة؛ لا فصل واجبات بين فريق غير موجود.

النشر يثبت إصدارًا، وwidget يستخدم معرفة مصرحًا بنشرها وجلسات 10 دقائق دون تعليمات خاصة أو كتابة. مفاتيح API الخلفية محدودة بالوكيل، مخزنة كبصمات، مدتها 90 يومًا وقابلة للإلغاء. إزالة القسم المرئي لم تلغِ المفاتيح الموجودة.

## ما لم ينفذ أو لم يتحقق بعد؟

[BACKLOG](BACKLOG.md) هو القائمة التنفيذية بمعرفات ومعايير إغلاق. أهم البنود:

- **قبل الإطلاق التجاري العام:** استعادة حساب آمنة، وتشخيص تقطع الدخول والجلسات. لا تغيير تلقائي لإعدادات Auth/SMTP أو إرسال بريد Supabase افتراضي.
- **قدرات غير منفذة:** فوترة ودفع واشتراكات؛ CRM/ERP/helpdesk/webhooks/OAuth؛ دعوات وأدوار فريق؛ embeddings/PDF/صور/URL ingestion؛ queue/outbox ومهام طويلة؛ مشتريات فعلية وأوامر شراء.
- **تشغيل يحتاج استكمالًا:** سياسة احتفاظ واستعادة نسخة كاملة؛ مراقبة وتنبيهات وتشخيص منقح؛ قياسات حمل وأداء ممثلة؛ مراجعة وصول أوسع؛ حسم حدود موافقة الموجز والحصة.
- **محتوى وتجهيز تجاري:** نصوص خصوصية وشروط معتمدة، فحص أسماء تجارية، حالات عملاء حقيقية بأذونات، صفحات قطاع مستقلة، CMS/منصة ترجمة، تحقق تجاري ووصول عملاء. لم تنفذ حملة أو رسائل مبيعات.
- **وصول غير مثبت:** اتصال NEXA Agent لم يتحقق. المالك عيّن المساعد وNEXA Agent للتنفيذ؛ الوقت والميزانية والوصول التجاري لم تُحسم. وجود 11 اتصال تصميم مؤكد من المالك ليس إثبات دمجها في runtime.

ليست قيود Qwen الداخلي، أو التسجيل بلا بريد، أو إزالة واجهة API أعمالًا ناقصة: هي قرارات نطاق مقصودة. رفض سؤال بلا مصادر سلوك مقصود، مع إصلاح تجربة التعريف والرسالة والإرشاد.
