## قراءة الأدلة والتراجع

تقارير A/B وحالات عدم النشر فيها لوقتها؛ نشر A–E اللاحق مثبت. تقارير المنتج لا تُمحى عند إصلاح عيب؛ تُربط بالإصلاح وحدوده. [التقرير الشامل](CURRENT-IMPLEMENTATION-2026-10-20.md) يجمع هذه الحدود، و[فهرس الأدلة](evidence/README.md) يحفظ الملفات.

إصدار أقدم ليس خيار تراجع صالحًا تلقائيًا: قد يفقد الحسابات أو Studio أو إصلاحات لاحقة. اتبع [WORKFLOW](WORKFLOW.md)، وحدد توافق الكود مع قاعدة البيانات الحالية، واحتفظ بالبيانات. لم تُجرَ تجربة استعادة نسخة إنتاج كاملة. تعطيل Studio بحاجز الخادم لا يحذف البيانات.
