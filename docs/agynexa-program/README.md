# مركز توثيق AGYNEXA

الحالة الجارية: [Agent Studio C/D/E](agent-studio/STAGES-CDE.md) نُشر عبر PR #18 فوق الحسابات والموقع القائم. المصادر النصية والتشغيل والنشر وAPI وwidget منفذة. نتائج Groq والإيصال الفعلي في التقرير؛ استعادة الحساب والفوترة والتكاملات الخارجية فجوات منفصلة. توجيه المالك D-26 فوّض استكمال المراحل والنشر، مع تجميع الفحوص عند التسليم فقط.

مراجعة السوق مطابقة بالكود: نحتفظ بالقالبين ومحرك واحد والعزل والموافقات والأدلة، ولا ننفذ تحويل RFQ أو إعادة تصميم أو خدمات عشر مستقلة. الفقرات والتقارير الأقدم أدناه تاريخية؛ STATUS وRESUME وتقرير C/D/E هي نقطة الاستئناف الحالية.

## الوضع الحالي بوضوح

الموقع ثنائي اللغة منشور، مع 10 خدمات و9 حلول و64 عنوانًا تسويقيًا. أضيفت حسابات مستخدمين وتسجيل مباشر دون رسالة بريد، وجلسات دخول، وحفظ الموجزات وعرضها وحذفها مع RLS. صفحات الحساب الستة noindex خارج sitemap. في الإنتاج لا Studio أو معرفة حية. على الفرع توجد مساحة عمل ووكلاء محفوظون متحققون محليًا؛ [تسليم B](agent-studio/STAGE-B.md) يوضح حدود التفعيل.

آخر تسليم منتج: [PR #15](https://github.com/adham-younes/vzero/pull/15)، تنفيذ `e6adf5e` ودمج `558fef356a5fc1c8419ad0749fabcc6d1df4705f`. نجح البناء و10 اختبارات وحدات و22 فحص HTTP إنتاجي واختبارات عزل قاعدة البيانات ورحلة الجوال العربي. [التقرير والحدود](releases/ACCOUNTS-AND-BRIEFS-2026-10-20.md). الفيديو والهوية محفوظان؛ تصحيحات المرحلة 4 السابقة نُشرت بالفعل ولا تعاد.

## معاني الحالة

| الوسم | معناه |
|---|---|
| `CONNECTED_OWNER_CONFIRMED` | اتصال أكد المالك وجوده في Vercel Connect؛ تشغيل القدرة المطلوبة يفحص عند استخدامها |
| `IMPLEMENTED` | كود موجود في المستودع؛ راجع دليل تشغيله وحدود الاختبار |
| `VERIFIED` | فحص محدد نجح على بيئة وإصدار معلومين؛ ليس شهادة شاملة للمنتج |
| `SPECIFIED` | تصميم أو عقد أو مخطط فقط؛ لا تشغيل متصل مثبت |
| `REQUIRES_ACCESS` | يحتاج نطاقًا محددًا وحسابًا أو وصولًا مفوضًا قبل التنفيذ |
| `BLOCKED` | عائق محدد موثق؛ لا يُفترض أنه زال دون تحقق |
| `UNKNOWN` / `INFERRED` | معلومة غير مثبتة / استنتاج معلّم بوضوح |

## ترتيب المرجعية عند التعارض

1. توجيهات المالك المباشرة، مع تسجيل أثرها في [DECISIONS](DECISIONS.md).
2. الكود الحالي وأدلة الإصدار المحددة للحكم على ما يعمل فعلًا.
3. [STATUS](STATUS.json)، مصفوفة المراحل وعقد API الحالي للحالة الراهنة.
4. الخطة الأصلية للهدف والقيود، مع التفويضات اللاحقة المسجلة.
5. تقارير `releases/` وملفات `baseline/` كسجل تاريخي في تاريخها، وليست وصفًا دائمًا للحاضر.

ملفات `source-map.json` و`routes.json` و`dependencies.json` و`content-inventory.json` و`tool-inventory.json` تعكس جرد المرحلة 0. استُبقيت لأثر المراجعة. القائمة الحالية للمسارات في [current-routes.json](current-routes.json)، والتبعيات الفعلية في [package.json](../../package.json) وملف القفل.
