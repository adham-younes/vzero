# Search intent and page ownership

This map guides the drafts. Topics are editorial hypotheses; no paid keyword dataset, search volume, difficulty score or ranking forecast was available. Metadata for every language/route is exported in `metadata-inventory.json` and `metadata.csv`.

## The distinction that keeps the site coherent

The home page owns the Agent Builder product identity. Capability pages on the existing service routes explain agent roles and operating requirements. Solution pages explain a business task, its information and reviewable output. Architecture, integrations, security and methodology answer technical and purchasing questions. They should link to one another with descriptive text rather than repeat the same introduction.

## Language and search decisions

Use “AI agents” and “agentic systems” where they accurately name the offer; explain them in the body. Avoid repeating both in every heading. Internal family names such as AgentFabric are preserved identifiers, not assumed search demand.

في العربية نستخدم المصطلح الذي يشرح المهمة: «مقارنة عروض الموردين» أو «مراجعة الفواتير» أو «المعرفة المؤسسية». ولا نحشو كل عنوان بعبارة «حلول الذكاء الاصطناعي المتقدمة». تُحفظ الأسماء التجارية، ويُشرح دورها عند الحاجة.

One page should answer its main question sufficiently before linking onward. Repeated closing blocks and control labels are appropriate shared interface text. Repeated substantive paragraphs across service and solution pages should be avoided.

## What remains for a later implementation or measurement scope

- Validate search terms with site-specific Search Console queries and the chosen market/language, then refine priority rather than manufacture volumes.
- Check each language's canonical URL, hreflang, indexability, sitemap and crawlable internal links. No technical SEO change is made here.
- Keep account and Studio indexing decisions separate from marketing-page metadata.
- Add only structured data that matches visible, approved facts. FAQ prose is useful for readers; it does not guarantee a rich result.
- Establish an agreed baseline for qualified enquiries and useful page actions. A click, saved brief, delivered email and signed project are separate events.

The content aims to be useful and discoverable. Search position, traffic and AI-generated citations depend on factors beyond rewriting and have not been measured in this task.
