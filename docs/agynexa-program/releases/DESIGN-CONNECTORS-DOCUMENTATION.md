التحقق المخصص لهذه الحزمة: اكتمال 11 اسمًا وموردًا وعدم التكرار، توافق العدد والحالة مع STATUS، قراءة JSON وفحص الروابط المحلية وdiff. لا فحوص تطبيق أو تغيير منتج أو تشغيل مدفوع أو اختبار مصادقة موصلات ضمن هذا التوثيق.
