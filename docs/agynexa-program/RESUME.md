# استئناف AGYNEXA

التفويض الأحدث D-26: إكمال Studio C/D/E ثم نشر إنتاجي على vzero. main عند bd4b424 يحتوي إصلاح الحساب وحذف مصادر الأصول، وجرى دمجه في فرع PR #18. لا إعادة لإصلاح الحساب أو مراحل الموقع 0–6.

الكود الجديد في lib/studio وواجهة studio-agent ومسارات API. [تقرير C/D/E](agent-studio/STAGES-CDE.md) هو المرجع الجاري. مصادر نصية خاصة، lexical RAG، مفاتيح Groq الثلاثة، مقارنة متزامنة اختيارية، سجل التشغيل، موافقات الدعم، إصدارات ثابتة، API keys وwidget عام بمصادر معتمدة فقط.

التسليم قيد التحقق المجمع. Studio SQL أساس B وC/D يطبقان على مشروع xsyxvswbiptbyxyqhdim بحساب agynexa فقط بعد الفحص المحلي. لا تغييرات Auth أو SMTP أو بريد. Vercel connector يعيد 404؛ GitHub integration مسار النشر. المفاتيح الخادمية لا تتوفر محليًا؛ إثبات inference سيكون من الإصدار المنشور.

استعادة الحساب عائق للإطلاق التجاري العام؛ الفوترة والتكاملات الخارجية وPDF/embeddings خارج هذا النطاق. إعدادات التشغيل والتراجع في تقرير التسليم. الفيديو ومكوّناه محميان؛ لا إعادة تصميم.
