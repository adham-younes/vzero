# استئناف AGYNEXA

اكتمل نطاق Agent Studio A–E ونُشر إنتاجيًا بتفويض D-26. مصدر المنتج `b3665b8e91e223fc61883cb8703760b12a8c96ed` عبر PR #18 ثم #21 و#22. [التقرير الجاري](agent-studio/STAGES-CDE.md) و[إيصال الإنتاج](agent-studio/evidence/stage-cde/production.json). الموقع: https://vzero-nine-beryl.vercel.app/ar/studio. لا إعادة لمراحل الموقع 0–6 أو Studio A/B.

يعمل حفظ الوكلاء، مصادر النص/TXT/Markdown، الاسترجاع بالكلمات والاستشهادات، Groq، المقارنة المتزامنة، موافقات طلب الدعم الداخلية، الإصدارات، API وwidget عام بمصادر معتمدة. GPT-OSS 120B و20B للإنتاج؛ Qwen Preview للتقييم الداخلي فقط. نجح الاستدلال الفعلي بالمفاتيح الثلاثة. لا تغيير للفيديو أو مكوّنيه أو المحتوى المعتمد.

مهاجرات Studio الثلاث مطبقة على xsyxvswbiptbyxyqhdim بحساب agynexa فقط؛ [إيصال SQL](agent-studio/evidence/stage-cde/database.json) يربط timestamps المستضافة بالملفات. لا تعِد db push عميانيًا، لأن MCP ولّد timestamps مختلفة. لا تغييرات Auth أو SMTP أو إرسال بريد. بيانات التحقق المصطنعة وجلساتها وصلاحية evaluator حذفت.

الفحوص جمعت عند التسليم: بناء/TypeScript، 40 فحصًا محليًا موجهًا، عزل Data API، تقييم محدود، ودورة إنتاج من المقترح إلى الموافقة والنشر وAPI/widget ثم الإيقاف. أعيدت حالات الفشل فقط بعد التصحيح، لا الحزمة كاملة. سجلت استجابات جلسة 401 ومحاولة دخول 503 متقطعة ثم نجحت الجلسة والدورة النهائية؛ سبب التقطع غير مثبت ويحتاج متابعة قبل توسع الاستخدام. لقطة الموبايل تثبت التنقل/RTL، وليست فحصًا لكل إجراءات الواجهة.

الخطوة التالية ليست مرحلة Studio جديدة: اعتماد مسار استعادة حساب حقيقي قبل الإطلاق التجاري العام. الفوترة وCRM/ERP وPDF/embeddings ودعوة أعضاء آخرين غير منفذة. لا تغير Auth أو البريد تلقائيًا. التراجع: تعطيل Studio أو إعادة كود معروف مع إبقاء البيانات؛ لم تختبر استعادة نسخة إنتاج كاملة.
