أضيف فحص خادمي GET /api/health/supabase لإثبات اتصال التطبيق نفسه. يرفض المشروع الخطأ ولا يعرض أسرارًا. [حالة الاختبار](releases/SUPABASE-CONNECTION-2026-10-20.md) و[الدليل](evidence/supabase-connection-2026-10-20/verification.json).
