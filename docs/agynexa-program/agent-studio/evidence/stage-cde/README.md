# دليل أدلة التسليم

جميع البيانات التشغيلية هنا مصطنعة لهذا التسليم، بلا مفاتيح أو كلمات مرور. حساب التحقق ومساحته حذفا من الإنتاج بعد الفحص.

- production.json: المسار الإنتاجي النهائي ومصدر الإصدار وإيصال التنظيف.
- production-browser.json وproduction-studio-ar.png: دخول وتنقل وRTL بعرض390؛ اللقطة قبل اكتمال تحميل بيانات السجل.
- database.json: المهاجرات الثلاث وبصماتها ومطابقة timestamps التي أنشأها MCP.
- local.json وbrowser.json وrls.json: الفحوص المحلية والعزل المباشر؛ لا تنسب لها استدلالًا حيًا.
- provider-listing.json وcomparison.json: إتاحة المفاتيح والمقارنة المتزامنة الفعلية.
- evaluation.json: التقييم الأصلي،12حالة لكل من120B وQwen؛ لا إعادة كتابة النتائج بعد الإصلاح.
- targeted-followup-1.json ثم targeted-followup.json: إعادة الحالات التي فشلت فقط، على إصدارات التصحيح المتتابعة.
- approval-regression.json: معاملة محلية ملغاة تثبت إصلاح حفظ مقترح الدعم؛ الإنتاج يثبت الدورة الفعلية لاحقًا.
- session-interruption.json: استجابات401/login503 أثناء محاولات التحقق، قبل نجاح الدورة النهائية. السبب المتقطع غير مثبت.

[التقرير والقيود](../../STAGES-CDE.md). نجاح هذه العينات ليس تقييم تحميل أو دقة عامة أو ضمان توافر.
