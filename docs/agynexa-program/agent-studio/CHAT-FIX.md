# إصلاح المحادثة وعرض أنماط الإجابة

20 أكتوبر 2026. بلاغ المالك: سؤال «من أنت» يعيد رفضًا إنجليزيًا، ولا تبدو الواجهة مساحة دردشة، وتعرض معرفات النموذج وحالة succeeded.

السبب في `lib/studio/runtime.ts`: كل رسالة تمر باسترجاع المعرفة، حتى التحية والتعريف، ونص الامتناع يتبع لغة الوكيل المحفوظة. في `@components/studio-agent.tsx` تفتح المعرفة افتراضيًا وتظهر النتائج كبطاقات تشغيل أسفل النموذج، مع ID المزود وحالته. التقرير السابق أثبت API؛ لم يثبت ملاءمة هذه التجربة للمستخدم. هذا الإصلاح يعالج البلاغ دون إعادة مراحل البرنامج.

التغيير: المحادثة التبويب الأول والافتراضي، سجل رسائل محدود الارتفاع، رسالة المستخدم تظهر فورًا مع حالة انتظار، خانة إرسال أسفل الرسائل وEnter/Shift+Enter وإيقاف ومحادثة جديدة. السجل يسمح بفتح محادثة محفوظة. تظهر المصادر عند توسيع «مصادر الإجابة». تعرض الواجهة «متقدم / سريع / تقييم داخلي» وحالات عربية/إنجليزية بدل IDs وsucceeded؛ IDs الأصلية تبقى في API والسجلات الخادمية، ولا نعيد تسمية النماذج فعليًا أو ندعي ملكيتها.

`lib/studio/conversation.ts` يجيب على رسائل تعريف/تحية/شكر كاملة ومحددة دون استدعاء مزود أو حاجة إلى مستند. هذه ردود منتج ثابتة تسجل في run مع response_kind=conversation وتكلفة/tokens صفر، وليست استدلالًا حيًا من Groq. الرسالة التي تجمع تحية مع سؤال أعمال أو تعليمات لا تتجاوز الاسترجاع. بقية الأسئلة تبقى محكومة بالمصادر وRLS؛ لا إجابات عامة مختلقة. اللغة تتبع حروف رسالة المستخدم الحالية ثم لغة الوكيل عند غياب دلالة، بما فيها رسالة نقص المعرفة. عند غياب المصادر، توضح للمالك أين يضيفها دون مطالبة مستخدم widget بفتح إعدادات لا يملكها.

مراجعة السوق المعتمدة مقروءة في التسليم السابق ومطابقة مجددًا لهذه الفجوة: النطاق المحدود والأدلة والعزل باقية، مع إصلاح تجربة الوظيفة الأساسية. لا تحويل RFQ أو صور أو إعادة تصميم تسويقي. قرئ CONNECTED-DESIGN-TOOLS وDESIGN؛ الإصلاح يستخدم مكونات Button/Input والتوكنز القائمة، ولا يتطلب توليد أصل أو تشغيل موصل تصميم. لا مهاجرات أو تغيير Auth أو أسرار أو Hero.

التحقق مجمع عند التسليم فقط: بناء و14 تحققًا منطقيًا موجهًا، ورحلة متصفح محلية بقاعدة معزولة حقيقية لرسالة «من أنت»، سؤال بلا دليل، عرض العربية390 والإنجليزية1440. لا حساب إنتاج مصطنع جديد. حالة التنفيذ والنشر الفعلية ستثبت في إيصال هذا المجلد؛ لا ينسب فحص محلي إلى الإنتاج.
