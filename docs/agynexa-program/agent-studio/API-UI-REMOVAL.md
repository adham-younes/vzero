# إزالة قسم مفاتيح API من واجهة الوكيل

20 أكتوبر 2026، بطلب المالك. حذف قسم «مفاتيح API الخاصة» كاملًا من Studio بالعربية والإنجليزية: الشرح، حقل الاسم، الإنشاء، عرض القيمة، قائمة المفاتيح وإلغاؤها، ومثال POST/Authorization. اسم التبويب أصبح «النشر» فقط. حذفت الحالة المحلية والتعريفات التي تخص عناصر القسم المحذوفة.

الملف: `@components/studio-agent.tsx`. هذا تعديل عرض؛ لا إلغاء لمفاتيح قائمة أو تغيير مسارات الخادم أو الصلاحيات أو قاعدة البيانات. تبقى المحادثة ونشر الوكيل والـwidget كما هي. التقارير السابقة التي تصف إنشاء المفتاح من الواجهة تاريخية؛ عقد API الخادمي ما زال موثقًا في OpenAPI.

التسليم يستخدم بناء Vercel وفحصًا محدودًا للأصول المنشورة، دون إعادة حزمة الاختبارات أو إنشاء حساب حي. حالة النشر النهائية تسجل في STATUS وإيصال هذا التقرير. المكونات القائمة تكفي للحذف؛ لا حاجة لموصل تصميم أو أصل جديد. لا تغييرات للفيديو أو الهوية أو المحتوى التسويقي.
