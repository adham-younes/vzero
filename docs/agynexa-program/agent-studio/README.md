## حدود التفويض

الفرع `codex/agynexa-studio-stage-a` مشتق من main. يسمح بمعاينة معزولة وPR للمراجعة، ولا يسمح بالدفع إلى main أو الدمج أو Production. لا يغير هذا التكليف `agynexa.si` أو مشروع Adham-AI-Agent-.

مهاجرتا الحسابات السابقتان مطبقتان: `20261020074037` و`20261020074207`. لا migrations جديدة في A، ولا تعديل لإعدادات Auth أو بيانات حية. تطوير B يحتاج بيئة معزولة؛ تطبيق أي migration على قاعدة قائمة يحتاج موافقة مستقلة تحدد المشروع والإجراء.

يستمر التسجيل بكلمة مرور دون تأكيد أو OTP أو magic link أو ترحيب بريدي. `email_confirm:true` لا يثبت ملكية البريد. لا عضوية أو دور بحسب البريد، ولا OAuth/دمج تلقائي أو SMTP أو استعادة بريدية في A. استعادة حساب موثوقة عائق إطلاق تجاري حتى اعتماد مسار يدعمه المزود واختباره.

Groq المدفوع مفوض للاختبارات والتشغيل ضمن مرحلة C باستخدام مفتاح خادمي. لا فحص نموذج أو صرف في A. النموذج الافتراضي المقترح `openai/gpt-oss-120b`؛ `qwen/qwen3.8-27b` للتقييم الداخلي ما دام Preview، مع إعادة التحقق من التوافر والميزات وقت التنفيذ. لا اعتماد على embeddings غير متاحة؛ يسمح التكليف باسترجاع PostgreSQL نصي فعلي عند الحاجة.

القالبان KnowledgeGrid وServiceFlow يعملان مستقبلًا فوق Runtime واحد. لا Studio أو وكيل محفوظ أو RAG أو نشر وكيل منفذ حاليًا. `@components/agent-workspace.tsx` مكوّن قديم غير مستورد في المسارات الحالية؛ صفحة AgentNexOS تعريفية.
