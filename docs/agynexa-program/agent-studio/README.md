امتداد للموقع القائم وفق [التكليف الأصلي](EXECUTION-PLAN.md)، مع تفويض [D-26](../DECISIONS.md) بإكمال المراحل والنشر الإنتاجي. نطاق A–E منشور؛ الاستعداد التجاري العام له فجوات صريحة. [التقرير والأدلة الحالية](STAGES-CDE.md).

| المرحلة | النطاق | الحالة |
|---|---|---|
| A | تصحيح CSS للمقدمة وحفظ الفيديو ومكوّنيه | DEPLOYED؛ لا تعديل إضافي للمقدمة |
| B | مساحة مالك واحد وقالبان ووكلاء محفوظون | DEPLOYED؛ SQL مستضاف وعزل RLS |
| C | معرفة نصية وGroq واسترجاع واستشهادات وتقييم | VERIFIED_PRODUCTION ضمن الحالات الموثقة |
| D | طلب دعم بموافقة وإصدارات وAPI وwidget | VERIFIED_PRODUCTION؛ لا CRM أو بريد |
| E | إيصال نشر وأدلة وحدود تشغيل وتراجع | DELIVERED_WITH_COMMERCIAL_GAPS |

ابدأ من [/ar/studio](https://vzero-nine-beryl.vercel.app/ar/studio) بعد الدخول: أنشئ مساحة ووكيلًا، أضف مصدر معرفة، ثم اختبر المحادثة. اختر نمط «متقدم» أو «سريع»؛ المقارنة تشغلهما بالتزامن عند تفعيلها. Qwen عبر المفتاح الثالث تحقق فعليًا لكنه Preview للتقييم الداخلي، وليس اختيارًا عامًا أو fallback.

للنشر احفظ الإعدادات، اختر «النشر»، ثم انشر إصدارًا ثابتًا. للـwidget اعتمد مصدرًا عامًا صراحة ثم فعّله وانسخ iframe. قسم مفاتيح API أزيل من الواجهة بطلب المالك؛ [التقرير](API-UI-REMOVAL.md). موافقة ServiceFlow تنشئ سجل دعم داخليًا فقط.

تقارير [A](STAGE-A.md) و[B](STAGE-B.md) تاريخية؛ وصف عدم النشر فيها يخص وقتها. أحدث تعديل للواجهة `4b7b5a2` عبر PR #26، بعد إصلاح المحادثة في #24. قاعدة xsyxvswbiptbyxyqhdim فقط؛ مشروع Adham-AI-Agent- وagynexa.si خارج العمل.

استعادة الحساب عائق إطلاق تجاري. الفوترة والتكاملات الخارجية والبحث الدلالي/PDF غير منفذة. سجلت محاولات جلسة متقطعة أثناء التحقق ثم نجح المسار النهائي؛ سببها لم يثبت. التفاصيل والنتائج الأصلية محفوظة في التقرير.
