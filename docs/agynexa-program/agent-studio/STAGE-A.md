## نتيجة التشخيص والتغيير

القياس قبل التغيير وجد `rgba(5,5,5,0.05)` على `.video-tint` في الكمبيوتر والجوال. شفافية الفيديو وعناصره الأب 1، وfilter وbackdrop-filter تساوي none وmix-blend-mode يساوي normal. فحصت ::before/::after والـz-index والعزل، ولم أجد طبقة pseudo مرسومة تضيف تعتيمًا. لا دليل يربط اختلاف لون العنوان بسبب الشكوى.

التغيير في app/globals.css فقط: خلفية الطبقة تصبح transparent تحت `.home-page`، وإزالة إعادة تعريف التعتيم في media query للجوال. لا brightness تعويضي. هذا يزيل تعتيم 5% المتبقي فقط؛ لا يثبت أنه يفسر أي انخفاض كبير سابق أو اختلاف عرض على جهاز المالك. لا مرجع قديم افترض أنه معتمد؛ لقطات قبل التغيير هي الحالة الحالية وليست اعتمادًا بصريًا.

commit الإصلاح المستقل: `a332057`. يحتوي على ملف CSS واحد، سطرين مضافين وسطرين محذوفين. يمكن عكسه محليًا بـ`git revert a332057` دون أي إجراء قاعدة بيانات؛ النشر الإنتاجي لأي تراجع يحتاج تفويضه المستقل.

## التحقق المنفذ

- `node node_modules/next/dist/bin/next build`: نجح، بما فيه TypeScript، دون تثبيت أو تحديث تبعيات.
- Chromium محلي: مقارنة الإطار الثابت في dev على المقاسين، دون تجاوز أفقي أو أخطاء JavaScript للصفحة.
- [نسخة البناء المحلي](evidence/stage-a/runtime.json): الفيديو يتحرك تلقائيًا بكوده الأصلي، overlay شفاف وfilter none، نافذة البنية تفتح وتغلق بـEscape، العربية RTL والإنجليزية LTR، دون overflow أو page errors.
- قراءات محلية محدودة: signup العربي يعرض noindex، AgentNexOS يعرض الصفحة، الكتالوج يعيد 10 خدمات، sitemap يحافظ على 64 URL.
- تحقق التوثيق و`git diff --check` يسجلان في دليل التسليم. لم تشغّل اختبارات تسجيل/كتابة/مهاجرات حية، أو تقييم Groq، أو اختبار الموقع كاملًا. لا مهمة lint معرفة ولا نجاح lint مدعى.
