# AGYNEXA — Brand Lock

المرجع هو القالب الحالي. القيم الدقيقة في [brand-lock.json](brand-lock.json)، وقد قورنت القيم الأساسية بالمتصفح المنشور.

| الدور | القيمة |
|---|---|
| الخلفية | `#050505` |
| النص | `#EBEBEB` |
| سطح البطاقة | `#0B0B0B` |
| النص الثانوي | `#BFBFBF` |
| اللون الأساسي والتركيز | `#10B981` |
| الحد | `#EBEBEB26` |

الخط العربي Almarai؛ الإنجليزي يستخدم خط النظام. عرض الحاوية الأقصى 1280px وحشوها الجانبي 24px. البطاقة الحالية بحافة 10px، والحقول 8px. مكونات الأزرار والحوارات والحقول الفعلية داخل `@ui/` بسبب aliases في tsconfig.

ملفات الفيديو والـHero محمية بالبصمة. مراقبة CSS وShell والأزرار والحوارات مهمة لأنها تؤثر عليه من خارج مكوناته. يسمح الملف المعتمد بإعادة بناء الأقسام بعد الـHero في المرحلة المخصصة؛ الخطة السابقة التي جمّدت الرئيسية كلها أصبحت مستبدلة.

نتيجة Better Design عن وجود وضع فاتح ليست معتمدة: قرأت قواعد أولية، بينما قواعد CSS الأخيرة والقيم المحسوبة في المتصفح تثبت الوضع الداكن. لم يُغيّر أي token أو theme.
