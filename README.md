## النطاق الحالي

المتاح فعليًا: 10 خدمات و9 حلول و64 عنوانًا تسويقيًا ثنائي اللغة، كتالوج تفاعلي ومثال مشتريات افتراضي، وحسابات وتسجيل مباشر بلا بريد وموجزات مشاريع دائمة. Agent Studio A–E منشور: مساحة خاصة ووكلاء محفوظون وقالبان ومعرفة نصية واسترجاع بالكلمات وGroq واستشهادات وموافقة دعم داخلية ونشر وAPI وwidget.

يوجد 34 عملية HTTP في 26 ملف route، وقاعدة Supabase متصلة. أحدث الإصلاحات: تجربة المحادثة واللغة وأسماء الأنماط، ثم إزالة قسم مفاتيح API من واجهة الوكيل دون تعطيل خادمه. استعادة الحساب والفوترة والتكاملات الخارجية غير منفذة، وتقطع الدخول يحتاج متابعة. ليست الخدمات العشر منتجات مستقلة أو استنساخًا لمنصة Kore.ai.

[التقرير الشامل: المنفذ والإصلاحات والمتبقي وحدود التحقق](docs/agynexa-program/CURRENT-IMPLEMENTATION-2026-10-20.md). آخر تغيير منتج #26 / `4b7b5a2`؛ تسليم التوثيق الحالي لا يغير التطبيق.

## تشغيل محلي

التقنيات: Next.js 16.4.0، React 19.2.4، TypeScript، Tailwind CSS 4، وpnpm 12.3.4. آخر تحقق محلي استخدم Node.js 26.8.2؛ هذا تسجيل للبيئة المختبرة وليس تحديدًا لنسخة Node في Vercel.

```bash
corepack pnpm install --frozen-lockfile
pnpm dev --port 3011
```

افتح `http://localhost:3011` أو `/ar`. صفحات التسويق والمثال لا تحتاج مفاتيح؛ الحسابات وStudio تحتاج إعدادات Supabase وGroq الخادمية كما في الخطة التقنية. استخدم قاعدة محلية معزولة للتحقق المحلي، ولا تنسخ أسرار الإنتاج. إذا لم يتوفر Corepack، استخدم pnpm 12.3.4 المثبت في بيئتك، ولا تعدّل ملف القفل لتجاوز مشكلة إعداد محلي.

تجمع الفحوص المناسبة عند تسليم منتج، وفق توجيه المالك؛ ليست مطلوبة بعد كل تعديل. أمثلة الأوامر:

```bash
pnpm build
node --experimental-strip-types --test tests/procurement.test.mjs
```

بعد تشغيل التطبيق في طرفية أخرى، يمكن تشغيل `node tests/http-smoke.mjs http://localhost:3011`. راجع [نطاق الفحوص](docs/agynexa-program/WORKFLOW.md) قبل تشغيلها؛ تعديلات التوثيق وحدها لا تستدعي بناء التطبيق.

## حماية الهوية والمحتوى

راجع [DESIGN.md](DESIGN.md) و[PRODUCT.md](PRODUCT.md) و[سجل القرارات](docs/agynexa-program/DECISIONS.md). ملفات الفيديو ومكوّنا Hero الأصليان محمية ببصمات ثابتة. تصحيح اللون وطبقة التعتيم تم بتوجيه مباشر من المالك؛ لا يعني ذلك تفويضًا بإعادة تصميم المقدمة. مجلدات المكونات الفعلية هي `@components/` و`@ui/` بحسب aliases في `tsconfig.json`.

المستودع عام. لا ترفع أسرارًا أو بيانات عملاء أو ملفات `.env` أو مخرجات حسابات خاصة. سجلات البحث العامة وثائق استدلال، وليست إذنًا بإعادة نشر أصول Kore.ai داخل المنتج.
